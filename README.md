# Поиск изображений по текстовому запросу (PoC)

**Задача.** Фотохостинг для профессиональных фотографов «Со смыслом» проверяет идею поиска референсных фотографий: пользователь вводит описание сцены, сервис показывает похожие фотографии. Нужно доказать осуществимость (PoC).

**Что сделано.** Агрегация экспертных и краудсорсинговых оценок соответствия пары «изображение — текст», очистка данных от недопустимого контента, векторизация изображений (ResNet, CLIP) и текстов (BERT, sentence-transformers), обучение нейросети, оценивающей соответствие числом от 0 до 1, сравнение с бейзлайном, рекомендации по развитию.

**Стек.** Python, PyTorch, transformers, sentence-transformers, CLIP, ResNet, scikit-learn, Optuna

**Результат.** рабочий прототип; сформулированы рекомендации по развитию продукта
